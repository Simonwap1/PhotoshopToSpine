# PhotoshopToSpine

Скрипт экспорта слоёв Photoshop в Spine (PNG + JSON).

В эту копию добавлена **русская локализация** интерфейса, подсказок и справки (версия 7.43).

Оригинал: https://github.com/EsotericSoftware/spine-scripts/tree/master/photoshop

## Установка

Скопируйте `PhotoshopToSpine.jsx` в папку:

`C:\Program Files\Adobe\Adobe Photoshop <версия>\Presets\Scripts\`

Затем в Photoshop: **Файл → Сценарии → PhotoshopToSpine**.

В диалоге выберите язык **Русский** (или «Автоматически», если интерфейс Photoshop на русском).
